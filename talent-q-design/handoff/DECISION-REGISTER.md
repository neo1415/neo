# Outstanding decisions

This register lists only decisions that are still open. Approved product and design decisions live in `decisions/`. "Founder" means a product or design trade-off that only the founder can make. "Engineering" means the next phase can decide it with the founder informed.

## Decided by the founder (29 Oct)

| # | Decision | What it means for the build | Where it is in the prototype |
|---|---|---|---|
| D1 | **Candidates can be found by unverified organisations too, but unverified accounts are limited.** | The default discovery rule is `ANYONE`. A candidate can still choose: employers and agencies with a verified domain, fully verified employers only, or nobody, and can hide from named organisations. Until an organisation is verified it **cannot post roles, can send at most 3 outreach messages a week, cannot run campaigns or submittals, and cannot see contact details**, and every message it sends tells the candidate it isn’t verified yet. The limits live in one place so they are easy to change. | `orgLimits`, `UNVERIFIED_LIMITS`, `outreachThisWeek`, `canDiscover` in `prototype/src/mock/world.ts`; Passport search options; Settings summary |
| D3 | **Verification is required before posting roles.** | A role brief can be drafted and approved internally, but publishing a listing needs a verified organisation: a verified domain plus a business registration check. Search is allowed before verification, under the D1 limits. | R1 verification step (`journeys/hire-a`) |
| D6 | **Use the industry standard taxonomy: ESCO, on ISCO-08.** | ESCO (European Skills, Competences, Qualifications and Occupations) is the open, freely licensed classification of about 3,000 occupations and 13,900 skills, with each occupation linked to the skills it needs. It is built on **ISCO-08**, the International Labour Organization’s standard occupation codes, which national statistics offices map to. The career atlas, gaps, matching and job tagging all use ESCO ids. Local job titles map to ESCO occupations through a maintained alias table. O*NET (US) was the alternative; it is US-specific. | Today `journeys/career/personas.ts` uses a hand-built set; production replaces it with ESCO ids |
| D8 | **English only at launch, built to be translated.** | Every user-facing string goes through a message catalogue keyed by id, with no text concatenated in code. Dates, times, numbers and currency use locale formatting (`Intl`). Layouts allow longer strings. Q’s replies are generated per locale. Adding a language is configuration plus translation, not a code change. | The prototype writes English inline. The production frontend must start with the catalogue (module M19). |
